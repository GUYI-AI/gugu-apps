# 美团（实验性）

让 agent 用它自己会话里的咕咕浏览器页签、用你自己的美团登录，在**美团网页版**（i.meituan.com、www.meituan.com、外卖 H5）上搜商家、美食、团购和酒店，帮你比较、看详情、把东西加进购物车。

**实验性，依赖美团网页版。** 美团没有官方公开接口，本 App 只是一份写给 agent 的操作说明（skill），不带程序、不要账号密钥、不联网。美团网页一改，某些步骤就可能失效；失效时 agent 会直接告诉你哪一步不行，不会编结果。

- **需要浏览器工具**：桌面端请同时安装并启用「Browser Use」App。
- **登录和验证由你来**：agent 不会在聊天里要密码、短信验证码或支付密码；需要登录、验证码、滑块时，它会请你在浏览器页签里自己完成。
- **下单和付款永远由你确认**：agent 最多把页面带到确认订单这一步、告诉你内容和金额，然后交给你；它不会自己提交订单或付款。
- **城市和地址**：结果取决于城市和地址，没说的话 agent 会先问你。
- 外卖 H5 常常要求登录、地址，或者跳转到美团 App；打不开时 agent 会照实说。

本 App 与美团公司无关。

源码：本仓 `sources/meituan-web/`，安装包目录 `app/`。
