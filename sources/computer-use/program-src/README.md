# Computer Use program adapter

This App uses a normal stdio MCP program and Gugu API 30 task-call, surface and projection capabilities. Its 0.5.0 manifest activates the App-owned command; it requires the #1607 foundation before installation. The App and host-removal PRs are one migration unit: publish and install a working market version before merging host removal. The host has no native-executor fallback for this App. This branch is not a published or accepted market version.

The private host-owned transport stamps `gugu/agent` and `gugu/sessionId`. The adapter rejects missing identities and never accepts them as tool arguments. These are trust assertions from Gugu's gateway, not signatures that a standalone pipe can independently authenticate. Each task retains its native owner. Native image blocks remain MCP image blocks; results are not JSON-encoded into text.

Single-call SDK cancellation reaches native preparation and execution. Preparation subscriptions remain independent. Program EOF, stdin close/error, stdout errors (including EPIPE), and SIGTERM/SIGINT dispose the native runtime and abort pending work. A late completed preparation cannot resurrect the runtime. The host foundation supplies upgrade-drain versus immediate-revocation integration; installed acceptance must verify that path.

The protected host is read from actual process ancestry, including the main process above its runtime worker. Missing or changed ancestry fails closed. The POSIX process query explicitly uses UTF-8 so Chinese package paths survive an empty inherited environment. macOS package names and bundle IDs are read from the enclosing App; Windows uses a fixed non-interactive process query. Only fixture coverage is available for Windows at this stage; native Windows execution remains acceptance work.

App-only tools read task-private preview metadata, read driver permission state without prompts, and open one of the two fixed settings panes. Model callers cannot invoke them. An agent working a page may read state but cannot open settings as the person. Opening settings does not grant permission. There is no status/grant helper API or extra human-wait interface. Consent blockers return immediately for the agent to discuss through its existing conversation or AskUserQuestion.

Tool discovery reads a committed schema snapshot from the pinned, verified driver; discovery never downloads or starts a daemon. `native/update-tool-specs.mjs` reproduces the snapshot without operating a window. The snapshot was inspected on macOS; platform execution checks remain necessary before activation. The actual binary is prepared only on first native use and has telemetry/self-updates disabled.

`node program-src/build.mjs` packages the adapter, pinned MCP SDK and PNG decoder into the App. It derives all bundled package dependencies from esbuild's metafile, requires their complete license texts and emits `THIRD-PARTY-NOTICES.txt`, including transitives. `--check` compares committed bytes. The PNG sampler compares actual pixels, independent of compression metadata. `npm test` exercises the actual SDK stdio transport as well as caller separation, cancellation, native cleanup, protected ancestry and image sampling. `npm run test:mutations` removes those boundaries in temporary copies and requires failures.

Confirmation is asserted by the agent with `confirmed:true` after deciding that it has approval. It is not a host-issued capability bound to the exact operation arguments.

`native/check-program.mjs` is an opt-in real Mac CLI/stdio probe. It uses synthetic host-shaped metadata, creates its own native window, reads the actual driver status, captures only that exact window and closes its owned processes. `GUGU_TEST_HOST_SDK_ROOT` can select the installed host SDK for compatibility checks. This is not an installed-Gugu gateway, permission-grant/revocation, independent TCC, remote transport, or final task-page acceptance test.

The custom MCP handler wraps each request in `gugu.withCall(request.params._meta, work)`. Display summaries come from host-stamped `gugu/agentName` and `gugu/taskTitle`. Resource creation happens only during that real task call. Background updates of already-held resources run in startup-created standard Node AsyncResources, so an ended or concurrent task cannot lend them authority.

The App selects and tracks its own target windows and paints the compact Stop/Continue bar in `control.html`; the host surface only handles presentation, conversion and cleanup. Windows physical bounds are converted through `surfaces.screen`, and `relativeTo` places the bar immediately above the chosen native window without permanent topmost behavior. A failed, rejected, hidden or stalled surface never admits or refuses an action. Native Stop and cancellation remain authoritative independently of rendering.

The Computer tab remains read-only. Each task has an authorized `gugu.projection` resource; screenshot bytes never enter page tool results or App-wide notifications. Successful actions retain at most 30 history entries and 16 task records. Visible pages request bounded, coalesced window captures on their own native lanes, checking the same real permissions and protected-host boundary. Source closure aborts capture and retires private state. Agent cursor state is sampled around the actual capture on the existing agent lane; only a stable sample matching the image dimensions is decorated. The page waits for `painted({sequence,width,height})` and joins by that exact receipt; missing metadata, reconnect invalidation and out-of-order arrivals hide the cursor. No planned pointer path or bitmap-over-network fallback is used. The first successful native call asks `showTaskPages()` to open this App's task pages; it never reopens a page after success and only retries failed presentation after 60 seconds.
