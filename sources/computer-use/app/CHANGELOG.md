# Changelog

## 0.2.0

改为显示咕咕自带的电脑控制：Agent 操作电脑走「设置 → 设备 → 这台电脑能做的事 → 电脑控制」，本 App 不再托管外部 Computer Use 程序，「MCP 程序」「启动参数」两项设置随之去掉。新增「电脑」页签：每个任务一份，agent 第一次操作电脑时自动出现在那个任务旁边，显示它正在操作的窗口的真实画面、它的光标和每一步。

## 0.1.2

换用轻透玻璃质感图标，保留渐变、高光与折射层次。

## 0.1.1

增加正式 App 图标：深青色显示器与指针。

## 0.1.0

首次发布：本机 Computer Use MCP 程序托管、自动发现已安装客户端、统一配置与真实错误状态。
