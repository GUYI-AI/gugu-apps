# Computer Use

通过本机的 Computer Use MCP 程序，让 Agent 查看和操作原生应用。打开 App 就是咕咕的统一配置与状态页，无需另外的业务页面。

macOS 上默认查找已经安装的 Codex Computer Use 客户端。也可以在「MCP 程序」中填写其他本机 Computer Use MCP 程序，在「启动参数」中填写它使用的 JSON 字符串数组，例如 `["mcp"]` 或 `[]`。命令直接启动，不通过 shell。

本 App 不包含第三方原生客户端、登录凭据或系统权限。客户端的安装、账号和系统授权沿用它自己的流程。「检查连接」确认 MCP 能否启动；实际操作失败时，状态页会保留返回的错误详情。进程在运行，不代表桌面操作已获授权。

Agent 的操作发生在这台电脑上，可能需要把目标应用放到前台。可以在状态页关闭 Agent 使用权限，在 App 管理页停用或卸载整个 App。关闭配置页不会停用能力。

需要支持 App API 5 的咕咕。源码在本仓 `sources/computer-use/`，安装包目录 `app/`；程序启动与协议转发代码均在包中。
