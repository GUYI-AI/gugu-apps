# Computer Use

让 Agent 查看和操作这台电脑上的原生应用。操作由咕咕自带的电脑控制完成，每个任务的 agent 有自己的光标。

**「电脑」页签**：每个任务一份。这个任务的 agent 第一次操作电脑时，它自动出现在任务对话旁边，不切走你正在看的页签。页签里是 agent 正在操作的那个窗口的真实画面、它的光标，以及它刚做的那一步。两个任务各看各的。

按任务分开的是画面和 agent 的光标；这台电脑的桌面、应用和真实键鼠只有一份。两个 agent 操作同一个应用窗口时仍会互相影响。

macOS 上第一次使用前，要在「系统设置 → 隐私与安全性」里给咕咕「屏幕录制」与「辅助功能」权限，由你本人打开。没有授权时操作会失败，原因写在那一步的工具结果里。

可以在 App 页关闭 Agent 使用权限，或停用、卸载整个 App。需要支持 App API 5 的咕咕。源码在本仓 `sources/computer-use/`，安装包目录 `app/`；「电脑」页签用的光标动画来自 trycua 的 cursor-motion（MIT，见 `CURSOR-LICENSE.md`）。
