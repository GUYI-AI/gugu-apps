Click the agent's name on the bar over the window it is operating: Gugu comes forward and opens the session that agent works in, or your private chat with it when that session is not on this computer. The bar looks the same; the name shows a hand cursor and an underline on hover, and the rest of the window stays usable as before.

Works best with a Gugu that has App interface 66. An older Gugu opens the session in its window without bringing it forward. The native driver remains 0.36.0-gugu.2.

Rollback: open Gugu Settings → Apps → Computer Use → Version history, and choose 0.5.2. Selecting an older version turns off automatic updates for this App until you enable them again. App data is preserved.
