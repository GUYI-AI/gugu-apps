Restores the pointer, click feedback, target and operation explanation in shared Computer Use pictures, including phone views. Feedback follows the picture and the actual operation; a live picture alone does not mean an operation is running.

Requires the new compatible Gugu Beta (App interface 58). Older Gugu clients keep their last compatible App release. The native driver remains 0.36.0-gugu.2.

Rollback: finish active Computer Use tasks, open Gugu Settings → Apps → Computer Use → Version history, and choose 0.5.1. Selecting an older version turns off automatic updates for this App until you enable them again. App data is preserved. Do not manually replace a cached driver.
