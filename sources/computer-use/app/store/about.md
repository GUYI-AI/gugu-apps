Lets agents operate the apps on this computer, and shows you what they do.

**The Computer tab**: one per task. The first time a task's agent operates the computer, the tab appears beside the task's conversation, without taking you away from the tab you are reading. It shows the real window the agent is working in, its cursor and the step it just took. Two tasks each see their own.

This App is the switch for computer control: while it is installed and on, agents (on this computer, and on your other computers) can operate apps on this computer; switch it off or uninstall it and this computer has no such ability, and agents do not see it. The actions come from Gugu's built-in computer control, fetched by an agent only when it needs them, not kept in every session.

The picture and the agent's cursor are per task; this computer's desktop, apps, keyboard and mouse are one. Two agents working in the same app window still affect each other.

On macOS Gugu needs two system permissions, Accessibility and Screen Recording: open this App and press Authorize under System permissions, which asks for both. Screen Recording takes effect after Gugu restarts. Without them an action fails, and the reason is written in that step's tool result.

The Computer tab's cursor animation comes from trycua's cursor-motion (MIT).
