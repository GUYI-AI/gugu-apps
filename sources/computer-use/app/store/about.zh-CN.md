让 agent 操作任务所在电脑的桌面应用，也让你看到它正在做什么。

**电脑页签**：每个任务各有一份。第一次成功使用时，页签会出现在任务对话旁边，保留你正在看的页签。它显示真实窗口、实际采样的 agent 光标和最近的步骤。每个任务只看得到自己的预览，预览页只用于查看。

电脑工具和原生驱动由这个 App 提供。停用或卸载 App 会撤下工具并停止它的程序。需要人处理的步骤会立即返回，由 agent 在原有对话中说明。你可以在紧凑的控制条上停止目标应用；显示条出错不会代替动作授权，也不会拦住动作。

画面和 agent 光标按任务隔离，电脑上的桌面、应用、键盘和鼠标仍然共用。两个 agent 操作同一个应用窗口，仍会互相影响。

在 macOS 上，实际运行的原生驱动会检查辅助功能和屏幕录制权限。App 的设置页显示真实状态，并能打开对应的系统设置。打开设置不等于授权，更改后请刷新状态。权限缺失时，对应步骤的工具结果会说明原因。

需要咕咕 App 接口 30。原生操作支持 macOS 和 Windows。电脑页的光标来自 trycua 的 cursor-motion（MIT）。
