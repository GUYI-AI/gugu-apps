# Changelog

## 0.2.1

市场上名字下面加一句副标题，产品页加三张真实使用截图；App 协议版本改为 7（只发给支持副标题的咕咕）。

## 0.2.0

- 咕咕办公有了自己的一页：电脑上从左栏或「App」打开，手机上从「App」页或群里的卡片打开。页面列出最近打开的文件和群，可以搜索所有群里的文件，默认包括演示稿、表格和 markdown。点 markdown 时，用群文件夹自己的编辑器打开。最近打开的记录在手机和电脑上是同一份(要咕咕 0.2.57 起)。

## 0.1.2

- 群文件夹里的演示稿和表格各有自己的图标，不再都画成咕咕办公的 App 图标(要咕咕 0.2.57 起)。

## 0.1.1

- 群文件夹里这份文件有了新版、改了名或被删了，页面当场跟上，不再整张列表重读一遍。
- 点一个 pill 打开的，就是那个 pill 指的那份文件和位置;在别的文件上不框，后点的那个说了算。
- 从正式版 0.2.54 升级上来的，手里是那一版带的咕咕办公(还没有表格);更新到这一版，就能在群文件夹里打开、改 .xlsx 了。

## 0.1.0

这是它在市场上的第一版：从市场装上的，可以卸载，有新版时在 App 页更新。

- 打开群文件夹里的演示稿（.pptx）和表格（.xlsx、.xlsm）；点选或框选要改的地方，作为 pill 交给 agent 去改，改好的是同一个文件的下一版。
- agent 用它自带的 skill `office` 读和改这些文件：演示稿一页页读、改文字和形状；表格读区域、写单元格，写回时把牵连到的公式重新算好。
- 代码现在在公开的 gugu-apps 仓库里(sources/office)。
