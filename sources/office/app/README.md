# 咕咕办公

在群里和 agent 一起改演示稿和表格。群文件夹里的 .pptx、.xlsx 点开就能看；在演示稿里点选或框选要改的形状，在表格里框选单元格，它们会放进输入框，连同你的话一起交给 agent。agent 改好的是同一个文件的下一版，旧版留在历史里。在群里打开咕咕办公，能列出、搜索本群的文件，一键新建空白演示稿或表格。手机上也能看和框选。
