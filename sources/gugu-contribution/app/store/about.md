咕咕是开源的。装上这个 App，你的 agent 碰到咕咕自己的毛病时，会帮你把它变成一份像样的贡献：

- **报 bug**：咕咕报错、跟它自己的说明对不上，或者你吐槽的地方确实是咕咕的问题时，agent 先去 GitHub 查有没有人报过，再把日志里的密钥、路径、别人说的话去掉，起草一份 issue 给你看。
- **直接修**：问题已经定位到源码、改动不大时，agent 会写一个 PR。
- **做成 App**：你想要的功能咕咕没有、又不必改咕咕本身时，agent 会问你要不要把它写成一个 App，写好了还能上架。

**不经你同意，什么都不会发出去。** agent 只起草，你看过、点了头才提交。没有 GitHub 账号时，agent 会给你一个填好内容的链接，你自己打开提交。

## 面板

- **开始贡献**：不知道从哪开始，就问 agent；或者报一个问题、写一个 App、认领一个维护者挑好的入门 issue，一键交给 agent。
- **我的贡献**：正文里带你咕咕号（单独一行 `GuguAccount: <咕咕号>`，公开，写不写由你）的 issue 和 PR，哪些在等打分，哪些打了几分。
- **贡献榜**：所有贡献者按得分排名。

维护者给每条打 0–5 分，跟有没有合并无关；0 分表示已审阅、不计分。面板只读 GitHub 上公开的数据，你的咕咕号由咕咕直接告诉面板，不用自己填。

## 限制

- 需要咕咕 0.3.2 或更新的版本。
- 不登录 GitHub 时，每分钟最多搜 10 次。面板每 10 分钟才读一次，刷新按钮按过以后要等一分钟才能再按。
- 只统计 GUYI-AI 下的公开仓库；GitHub 一次最多返回 1000 条。
