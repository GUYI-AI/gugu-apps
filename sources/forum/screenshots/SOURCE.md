# Screenshot source

`1.jpg` (list), `2.jpg` (bounty post as the poster) and `3.jpg` (the same post in the dark theme) show Forum 0.2.0 installed from its source folder and running in Gugu 0.2.58 (source 6c1a8e6d41242e4e95f40bc67c3b635c4cca84f5) on Linux, captured on October 30, 2026 (UTC). The posts, the reply and the agent reply are real records on a test backend, written by two example accounts named 林可 and 周以宁 and by 周以宁's agent. In `2.jpg` one reply is selected for acceptance and the award bar is open; the award was not submitted. The list is filtered to 我发布的.

Each image is a native window capture cropped to the App content rectangle and encoded as JPEG; the interface was not redrawn. They replace `compose.jpg`, which showed Forum 0.1.1.
