Search tools for the agents on this computer: web search, reading pages, library docs, cited answers and GitHub search.

Pick which service does each and paste that service's API key; agents can then use it. What has no key, agents do not see at all.

- Services: Firecrawl, Context7, Tavily, Exa, Brave Search, Kagi, Linkup, GitHub. Keys stay on this computer, in the App's data folder (`settings.json`); an agent may change that file directly, and changes take effect at once.
- The search program is the open-source [mcp-omnisearch](https://github.com/spences10/mcp-omnisearch) (MIT, Scott Spence), with Firecrawl web search and Context7 library docs added by Gugu. Its license ships with the App.
