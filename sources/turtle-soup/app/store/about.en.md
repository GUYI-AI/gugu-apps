Play turtle soup (lateral-thinking puzzles) in a chat's side panel, or in a private chat with your own agent.

- **Start a round**: open Turtle Soup from the side panel, choose a difficulty and a puzzle (or a random one), pick an agent to host, and press Start. In a private chat with your agent it is the same. The App's own page only lists the rounds in each chat. A `.turtle-soup.json` round file appears in the chat's folder; everyone opens the same round, and questions and rulings appear for everyone live.
- **Ask**: ask questions a yes or no can answer. The host only ever picks one of yes / no / irrelevant / partly / please rephrase, and writes nothing else.
- **Solve**: when you think you have it, write the whole story and press Solve. The host rules solved / close (how many key facts it hits) / off track; only all the key facts count as solved, and then the answer is revealed to everyone.
- **Hint**: press Hint and the host gives the puzzle's own hints in order, three at most.
- **Give up**: when more than half the players press "Give up and show the answer", the host may reveal it. Playing alone, your press is enough.
- **Your own puzzle**: tell the host a puzzle privately, or ask it to make one up. The answer stays on its computer.
- **Play with agents**: ask an agent in the chat that has Turtle Soup to play along; it asks and solves with the player tools, shown in the App like a person's. It asks one question at a time and the App tells it quietly once ruled; when people are playing it asks in the chat before it submits a solution.

## The host and the answer

The host is an agent in the chat that has Turtle Soup and is given this chat on the Apps page ("which agents"). It follows the hosting rules the App brings: it takes over the round, rules, gives hints and reveals, and can start rounds with puzzles from outside the bank.

Everyone in a chat can read its folder, so **the answer is not in the round file**: until the round ends it exists only on the host's computer (the App's data folder) and in the host's own context. The host can only choose among fixed rulings and cannot write anything else, so there is nowhere to "explain" the answer away. A "solved" ruling is checked against all the key facts.

The host's owner can see the answer in the task's record: if you want to guess too, don't let your own agent host. Each ruling is one of the host's turns, paid from its owner's quota; questions waiting are ruled together.

## Agents as players

Agents with Turtle Soup that are given the chat can also play: ask, solve, ask for hints and vote to give up, like people.

An agent player sees only the round file, never the answer, and the host cannot ask in its own round. When the host rules (its question or another's), gives the hint it asked for, or the round ends, Turtle Soup on the host's computer tells it quietly, so it need not keep checking; while people are playing it waits for one of them before its next question. People get no such whispers; the App shows them live.

An agent player on the same computer as the host could technically read that computer's App data folder, and so the answer. It is told not to; for fairness, keep player agents and the host on different computers.

## Phone

On a phone you can start a round, ask, solve, ask for hints and vote (a phone can read and write chat files and notify the host). The host runs on a computer.

## The puzzle bank

109 puzzles (59 Chinese, 50 English): Soupbase's 50 stories (each in both languages), haiguitang-coop's 5 examples and 4 of Gugu's own. Each puzzle has its own author, source and license, which ship with the App. **Puzzles and App code are licensed separately**: the code is MIT, the puzzles under their own licenses (CC0 1.0, CC BY 4.0, CC BY-SA 4.0). The end of each round shows the puzzle's author, license and a link to the original. Puzzles without a license that allows shipping them with the App are not included.
