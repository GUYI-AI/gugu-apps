## 0.2.11

## 0.2.10

- 市场封面和产品页截图换成新的大厅与牌局（浅色、实际尺寸）。App 本身没有改动。

## 0.2.9

- 大厅改成一块深色舞台：语言、难度、题目是一点就选的胶囊，「开汤」是大按钮；下面这个群的牌局写清进行中 / 已还原 / 看了汤底、已问几次和谁玩过。别人开了新局、一局结束或删掉，开着的大厅随群文件变化当场更新，不用刷新。
- 牌局：汤面是一张案件卡；下面一行是主持人、已问几次、提示进度和玩家；每个问题右边一枚判定印章，等判定的是虚线。「提问」是唯一主按钮，「要提示」「放弃，看汤底」降成文字链接；结束后汤底单独一张揭晓卡。
- 不在聊天里打开时，没有牌局就说明牌局要在群聊或私聊里开。

## 0.2.1

- App 自己的整页（不在任何聊天里打开时）也能开局：选一个聊天、选里面的 agent 当主持人、挑题，点「开汤」，这一局就开在那个聊天里，并且在那里打开。下面照旧列出你所有的牌局。
- 为此要读你在哪些聊天里、聊天里有谁（新权限「读你所在聊天的成员和消息」，即 chat:read）；需要更新到带这项能力的咕咕。

## 0.2.0

- agent 也能当玩家：新增玩家工具 `rounds`、`state`、`ask`、`guess`、`request_hint`、`give_up` 和玩家 skill `turtle-soup-player`。在群里叫它「一起玩」，它的提问和还原和人的一样显示在 App 里，带它的头像。
- 一次一问：agent 上一个问题还没判，就不能再问。主持人判了它的或别人的问题、给了它要的提示、或者一局结束，海龟汤会悄悄告诉它，不用它反复来看；有人在玩时，它等人问过一个再问下一个，和人轮流来。这些悄悄话它不回，群里不会多出播报。
- 玩家工具只读牌局文件，拿不到汤底；主持人不能用玩家工具给自己的局提问。
- 群文件夹里的牌局文件显示海龟汤自己的文件图标（汤碗里探出一只小海龟），点开直接用海龟汤打开。
- App 自己的整页（不在任何聊天里打开时）列出你所在聊天里的全部牌局，点一局就在它的聊天里打开。
- 牌局文件只多了一个 `agents` 字段，0.1.x 照样能打开、能玩；主持人那台还是 0.1.x 时，agent 玩家收不到通知，会隔几分钟自己看一次。

## 0.1.2

- 主持人自己出的题，结算页署名统一显示「题目：主持人自出」，不再显示主持人填的文字（之前会显示成一串 user: 开头的 id）。
- 主持人判题以后不再往群里发「已判定」之类的消息：判定、提示、结局都在 App 里，所有人实时看得到。群里只在开局时说一句。

## 0.1.1

- 新图标：咕咕抱着一碗汤，汤里探出一只小海龟，头上一个问号。和别的咕咕 App 同一个画风，小尺寸下也认得出。

## 0.1.0

第一版：在群右栏，或者在和 agent 的私聊里，开一局海龟汤。

- 群里一个装了海龟汤的 agent 当主持人。提问只判「是 / 不是 / 无关 / 是也不是 / 请换个问法」，还原判「成功 / 接近 / 方向不对」，命中全部必要事实才算成功。
- 提示是题目自带的三级提示，由玩家来要。过半数玩家投票放弃才揭晓，一个人玩时一票就够。
- 汤底只放在主持人那台电脑上，一局结束前不进群文件；主持人只能选固定选项，写不了文字。
- 题库 109 份（Soupbase 50 个故事 × 中英、haiguitang-coop 5 道、咕咕原创 4 道），逐题署名并标明许可。
- 主持人也能用一道自己的题开局。
