# Changelog

## 0.1.1

- 新图标：咕咕抱着一碗汤，汤里探出一只小海龟，头上一个问号。和别的咕咕 App 同一个画风，小尺寸下也认得出。

## 0.1.0

第一版：在群右栏，或者在和 agent 的私聊里，开一局海龟汤。

- 群里一个装了海龟汤的 agent 当主持人。提问只判「是 / 不是 / 无关 / 是也不是 / 请换个问法」，还原判「成功 / 接近 / 方向不对」，命中全部必要事实才算成功。
- 提示是题目自带的三级提示，由玩家来要。过半数玩家投票放弃才揭晓，一个人玩时一票就够。
- 汤底只放在主持人那台电脑上，一局结束前不进群文件；主持人只能选固定选项，写不了文字。
- 题库 109 份（Soupbase 50 个故事 × 中英、haiguitang-coop 5 道、咕咕原创 4 道），逐题署名并标明许可。
- 主持人也能用一道自己的题开局。
