# 海龟汤

在群右栏，或者和自己的 agent 的私聊里玩海龟汤（情境推理）。

- **开一局**：右栏打开海龟汤，挑一道题（或随机），选一个 agent 当主持人，点「开汤」。群文件夹里多出一个 `.turtle-soup.json` 牌局文件，大家打开的是同一局，问题和回答实时出现在每个人那里。
- **提问**：问能用「是 / 不是」回答的问题，主持人答「是 / 不是 / 无关 / 是也不是」。觉得想通了就点「猜汤底」，主持人判你猜中了哪几条关键；关键全部找到，汤底就揭晓给所有人。
- **放弃**：过半数玩家点「放弃，看汤底」，主持人揭晓。一个人玩时点一下就行。
- **自己出题**：私下把题告诉主持人（或请它现编一道），它用 `create` 开局，汤底只留在它那台电脑上。

## 主持人与汤底

主持人是群里一个装了海龟汤、并在 App 页「给哪些 agent」里给了这个群的 agent。它用 App 带来的工具和 skill 主持：

| 工具 | 做什么 |
|---|---|
| `host({ game })` | 接手一局，拿到汤底和关键 |
| `pending({ game })` | 等着判的问题 |
| `judge({ game, answers })` | 一次判多条：问题给结论，猜测给猜中的关键 |
| `hint({ game, text })` | 给提示，每局最多 3 条 |
| `reveal({ game })` | 玩家投票放弃后揭晓 |
| `create({ chat, title, surface, bottom, key_points })` | 用题库外的一道题开局 |

群文件夹里的文件群里每个人都读得到，所以**汤底不进牌局文件**，在揭晓之前只在主持人那台电脑上（App 的数据夹）和主持人自己的上下文里。主持人的回答和提示里出现汤底里玩家还没见过的连续 5 个字，工具就拒绝写入。主持人看得到汤底：要一起猜的人，别用自己的 agent 当主持。

## 手机

手机上能开局、提问、猜、投票（读写群文件和通知主持人这几样手机都有）；主持人的 agent 跑在电脑上。

## 题库

题目在 `program/puzzles.json`（带汤底，只有主持人的程序读），页面读的是由它生成、去掉汤底和关键的 `bank/index.json`。每道题写明出处和授权，没有能随 App 分发的授权的题不收。
