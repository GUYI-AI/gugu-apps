See a PR and merge it without leaving the chat.

An agent sends a PR as a card: its title, how many files changed, where the checks are and whether it is approved, at a glance. "View changes" opens the diff file by file. When every check is green, "Merge" opens a confirmation that checks the head, the checks and your GitHub identity once more, then merges as you. If someone pushes a new commit after you confirm, GitHub refuses the merge and the card reads the PR again.

The card reads GitHub once when it opens and once more before a merge; it never refreshes on a timer. Only a person's own click merges; an agent cannot. It uses one GitHub credential from your password vault (by default the one the GitHub connector uses; change it in the App's permissions). The credential only goes into the header of requests to api.github.com, and the App never sees it. Any repository works: the card shows what your credential can read and merges where it may. Opened on its own, the App asks for a PR link. On a phone the card shows the PR title and opens GitHub.
