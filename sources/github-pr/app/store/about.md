在群里看一个 PR、合一个 PR，不用跳到 GitHub。

agent 把 PR 发成一张卡片：标题、改了几个文件、检查跑到哪一步、有没有批准，一眼就清楚。「查看改动」逐个文件展开 diff；检查全绿时点「合并」，确认框会再核对一次 head、检查结果和你的 GitHub 身份，然后以你的身份合并。确认之后要是有人又推了新提交，GitHub 会拒绝这次合并，卡片也会刷新。

卡片只在打开时读一次 GitHub，点合并前再读一次，不会定时刷新。只有人亲手点的才算数，agent 按不了合并。用的是你密码库里的一份 GitHub 凭据（默认是 GitHub 连接器在用的那份，在 App 的权限里可以换）：它只放进发往 api.github.com 的请求头，App 自己看不到。只支持 GUYI-AI 组织的 PR。手机上只显示 PR 的标题，并能跳转到 GitHub。
