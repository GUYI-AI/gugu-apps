# Changelog

## 0.3.0

Every page you have written is in one list: the pages of every chat you are in and the ones kept on this device. The list is the same wherever it opens; only its order changes: opened in a chat, that chat's pages come first; opened on its own, this device's; the rest follow, newest first. A narrow panel shows the list or the page, a wide one both. New page, search, rename and delete are in the list. A page nobody named takes its first line as its name. Pages kept on this device can be many now; picking an agent takes one into a new page of your private chat with it.
所有写过的笔记都在一个列表里：你所在的每个聊天里的页，和只存在这台设备上的页。列表在哪里打开都是同一份，只是顺序不同：在聊天里打开，先列这个聊天里写的；单独打开，先列这台设备上的；其余按时间排在后面。窄的面板里列表和纸切换着看，宽的并排。列表里可以新建一页、搜索、改名、删除；没起名字的页会用第一行当名字。这台设备上现在可以有很多页；选一个 agent 时，这一页会带进和它的私聊，成为那里的新一页。

## 0.2.0

The App's own page (the dock, a phone's App list) works on its own. Start writing at once, alone, on a page kept only on this device; or pick one of your agents and write with it, on the page of your private chat with it. Asking for a look while writing alone picks an agent first and takes what you wrote along: it is written into that chat's page and read back before the copy on this device is let go. The header switches agents; the tab reopens where you left it. Opened in a chat, nothing changes. Needs apiVersion 31 (gugu's agent picker).
App 自己的页面（侧栏 dock、手机的 App 列表）可以单独用了：可以直接开始写，纸只存在这台设备上；也可以选一个自己的 agent 陪你写，纸存在你和它的私聊里。自己写着的时候点「请它看一眼」，会先请你选一个 agent，再把写好的字带进和它的私聊——先写进去、读回来确认，才清掉这台设备上的那份。页头可以换 agent，下次打开回到上次那一页。在聊天里打开时和以前一样。

## 0.1.0

First version. A writing page in a chat's side panel; the chat's agent reads along through three tools (`read`, `annotate`, `reply`) and leaves notes in the margin.
