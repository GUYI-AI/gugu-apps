# Market media sources

The screenshots are real captures of the Gugu desktop client (a dev build of `GUYI-AI/gugu@3f2c1e3cca2c2d9167e1f145430e715f9bfa3fc5`) running against the shared test backend, with type and memory 0.1.0 installed from its folder through the App page. Light theme, 1600 × 1000 window, captured from the screen at device scale 1 without scaling or editing.

The agent is a Claude Code agent on the model 咕咕 Claude Opus 5.5; its name and avatar are the product's own. The text was typed into the App; every note, the reply under a note and the agent's answer were produced live by the agent through the App's tools.

- `1.png`: the App full width in a private chat with the agent: five noted phrases, the notes in the margin, one note opened with the writer's reply and the agent's answer.
- `2.png`: the App in the side panel of a group chat, with the whispers the App sent to the agent in the chat and a note in the bottom tray.

`0-promo.png` (1600 × 900) is rendered from `scripts/promo/type-and-memory.html`, which shows a crop of `1.png`, scaled only. The icon is unchanged.
