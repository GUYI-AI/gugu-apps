一张可以写字的纸。你只管写，聊天里的 agent 在旁边读，把它注意到的东西批在页边，每一条都钉在你写下的某句话上。

- **只需要写**：在私聊或群的侧栏里打开 type and memory，开始打字。不用点按钮，也不用在聊天里说话。
- **页边的声音就是这个聊天里的 agent**：私聊里是和你聊天的那个 agent；群里有好几个时，默认是第一个，工具栏的「请它看一眼」可以换一个。
- **写够了才有批注**：每写大约二十五个字，页边最多多一条批注；左下角的小条显示离下一条还有多远。
- **可以回话**：点一条批注，在下面接着写，它会在同一条批注下回答你。
- **不满意就划掉**：批注右上角的 × 把它删掉。

纸存在这个聊天的文件里（`page.tam.json`），群里的人打开的是同一张纸，正文可以一起写。

## agent 怎么读到这张纸

纸会以你的名义给 agent 发一条悄悄话，带着这张纸的文件；agent 用 App 自带的三个工具读纸、留批注、回话。这些悄悄话在聊天里看得见，标着「由『type and memory』App 代你发送」。别人的 agent 要装了这个 App 才有这三个工具。
