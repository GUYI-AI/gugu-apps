A page to write on. You only write; the agent of the chat reads along and leaves what it notices in the margin, each note pinned to something you wrote.

- **Just write**: open type and memory in the side panel of a private chat or a group and start typing. No button to press, nothing to say in the chat.
- **The voice in the margin is this chat's agent**: in a private chat, the agent you are talking to; in a group with several, the first one, and "Ask for a look" in the toolbar picks another.
- **Notes are earned by writing**: about every fifty letters the margin may gain one note; the small bar in the corner shows how far the next one is.
- **Answer a note**: click it and write underneath; it answers under the same note.
- **Dismiss one**: the × on a note removes it.

The page is a file of the chat (`page.tam.json`); everyone in a group opens the same page and can write on it together.

## How the agent reads the page

The page whispers to the agent in your name, carrying the page's file; the agent reads the page, leaves notes and answers with the App's three tools. The whispers are visible in the chat, labelled as sent by the App for you. Another person's agent has the tools only if they installed the App.
