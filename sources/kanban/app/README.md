# 看板

你这台电脑上的一块任务看板。

- **在哪打开**：装好以后它在最左边的栏上，点开是整页。任务页标签栏的「+」里、每个群、私聊、话题右栏的「⋯」里也有它；在任务里打开时，新卡片可以顺手挂上这个任务。在哪打开都是同一块板，在一处拖一张卡，别处马上跟着变。
- **卡片挂任务**：「挂上当前任务」「挂任务…」从这台电脑的任务列表里挑。挂着的任务在跑、在等你批准、停了，都直接显示在卡上；等你的卡数在页签角标上。「进入任务」跳过去，「交给它」把这张卡放进那个任务的输入框，由你决定发不发。「开工」用这张卡起一个新任务（要你点），卡移到「进行中」。
- **就地看、就地改**：挂上任务里的文件或群文件，md、文本、代码、JSON、图片、视频直接在卡片里看；md 和文本能直接改，别人同时在改也不会丢字。html、pdf、office 这类现在点「用 App 打开」，平台的 peek 上线后改成在看板旁边打开。
- **agent 也来推卡**：本机的 agent 有看板的工具（`list`、`get`、`create`、`claim`、`move`、`comment`、`link`）和 skill。在群里对它说「把这条记到我的看板上」，它会建一张挂着那条消息的卡；交给它的卡，它会认领、推进到「待验收」，挂上它做的 PR 或文件。agent 用工具改的卡，在任务状态变化或你切回看板时显示（平台的通知上线后改成即时）。
- **数据在哪**：只在这台电脑上，App 的数据夹里（`board.json`）。同一台电脑换账号登录看到的也是这一块。卸载 App 时一起删掉。不上传，不跨设备同步。

## 权限

| 权限 | 用来 |
|---|---|
| 看本机全部 agent（`agents:read:all`） | 卡上显示挂着的任务的标题和状态；看不到对话内容 |
| 起 agent（`agents:control`） | 「开工」：只在你点的时候起任务，只管它自己起的 |
| 读、写文件（`files:read` / `files:write`） | 在卡片里就地看、改任务里的文件和群文件 |
| 给 agent 工具（`agents:tools`） | agent 的看板工具；看板的数据也只经它写入 |

不连网。
