# Changelog

## 0.1.0

- 一块本机的任务看板：四列（待办、进行中、待验收、完成），可以加列、改列名；卡片拖拽排序，窄的地方一次一列。
- 左侧栏整页、任务页标签、群、私聊、话题右栏都能打开，同一块板实时同步；数据只经 App 自己的程序写入，几处同时改不丢。
- 卡片挂本机任务：状态（在跑、等你批准、等你回答、回合结束、停了、出错）自动显示，等你的卡数在页签角标；进入任务、交给它、开工。
- 卡片挂任务里的文件、群文件、链接、PR、群消息；md、文本、图片、视频在卡片里就地看，md 和文本就地改。
- agent 工具 `list`、`get`、`create`、`claim`、`move`、`comment`、`link`，以及 skill `kanban`。
