看板、团队、决策合成一页，三个视图来回切换，再也不会「切到组织图就切不回去」。

- **团队视图**：你 → 每台机器的主管 → 车道，每条车道直接列出它认领的卡；没人认领的卡单独一栏。
- **谁负责什么**：卡片上显示负责人的头像、名字和状态（在跑 / 等你）；顶部一排头像，点一下只看这个人的卡，切视图也保持。
- **等你拍板**：agent 用 ask 提的问题出现在每个视图顶上，选项一点即答；答复记进账本，并带着卡片发回给提问的 agent，它会接着做。
- **卡片和 agent 互相点得到**：卡片里点负责人就打开 agent（它手上的卡、发消息、看对话、改挂/交接/归档）；没人认领的卡可以直接「派给…」某个 agent，它会自己认领。
- agent 的 list 工具现在会说清每张卡归谁、哪些等 owner 拍板、哪些没人认领。
