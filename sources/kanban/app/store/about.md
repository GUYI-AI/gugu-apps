人和 agent 共用的看板。一块看板可以放在两个位置：

- **本机看板**：保存在这台电脑上，记录你自己和本机各任务的工作。仅支持在电脑上使用。
- **群看板**：保存在群文件夹中（`协作看板.board.json`），群成员和各自的 agent 共同查看和推进，修改实时同步。手机上也可以查看和修改。

两处的卡片、页面和 agent 工具完全相同。

## 入口

- 左侧栏：打开为整页，默认显示本机看板；标题旁可切换到你所在对话的群看板。
- 任务页：标签栏「+」菜单，显示本机看板。在任务内新建卡片时，可直接关联该任务。
- 群、私聊：右栏「⋯」菜单，显示该来源对话的默认群看板，首次打开时创建。话题入口打开来源群或私聊的同一块看板，不为话题另建看板。
- 群文件夹中的 `.board.json` 文件：点击即用协作看板打开。

## 功能

- **卡片**：默认四列（待办、进行中、待验收、完成），可添加列、重命名列；在列头或每列底部添加卡片，拖拽排序和换列；拖到「完成」后可撤销。窄屏下看板显示为列表，进行中和待验收在前。
- **进度**：每张卡片可填写进度、在等、下一步、截止。填写了「在等」的卡片显示等待原因；关联了任务、处于进行中且超过 45 分钟未更新的卡片显示为未更新。
- **需要处理**：筛选出有等待事项、或关联任务待批准、待回复的卡片，数量显示在标签角标上。
- **关联任务**：卡片可关联任务，显示 agent 头像、任务状态（运行中、待批准、待回复、本轮完成、已停止、出错）和所在电脑。支持打开任务、转给任务（将卡片内容填入任务输入框，由你决定是否发送）和新建任务。
- **文件与链接**：卡片可关联任务文件、项目文件、群文件、链接、PR 和群消息。Markdown、文本、代码、JSON 可在卡片内查看和编辑，图片和视频可在卡片内查看；任何文件都可以在看板旁边打开。
- **三个视图**：看板（列）、团队、决策是同一页的三个视图，切换时筛选和打开的卡片都保留。
- **团队**：把你在各台电脑上的 agent 按「你 → 每台机器的主管 → 车道」排开，每条车道列出它认领的卡，没人认领的卡单独一栏。点开一个 agent 可以看它手上的卡、发消息、看对话、打开 PR；改挂主管、交接和归档在「更多」里，由那台机器的主管执行，主管不可归档，交接确认或 PR 已开出后才能归档。
- **谁负责什么**：卡片显示负责人的头像、名字和状态；顶部的头像一点，就只看这个人（或没人认领）的卡。没人认领的卡可以在卡片里「派给…」某个 agent。
- **等你拍板**：agent 提的问题在每个视图顶上、在卡片里和「决策」里都看得到，选项直接点；答复记进决定账本（作用范围：全舰队、某台机器、某条车道、某个版本），并发回给提问的 agent。
- **舰队卡片**：可以在群消息里发一张舰队卡片，打开时实时显示在跑、等你拍板、等 CI/审/合、出错的数量，点一下进入团队视图。
- **agent 一起推进**：任务里的 agent 也能看卡、认领、更新进度、移动和评论，修改人由咕咕记录。说「看看看板」或「把这张卡拿去做」就行。

## 数据

- 本机看板：保存在本机 App 数据目录（`board.json`），同一台电脑上的不同账号共用。卸载 App 时一并删除。不上传，不跨设备同步。
- 群看板：保存在来源群或私聊文件夹中，与其他共享文件一样由来源成员共享，保留历史版本。每个 `.board.json` 是独立看板，同名旧看板迁移后各自保留，不合并内容。卸载 App 不会删除。
