人和 agent 共用的看板。一块看板就是一张卡片列表，每张卡片是一件事。

## 一眼看清

卡片按需要谁来处理分组，顺序固定：

- **等你**：agent 问你的问题和可选的答案，一点就答复；答复会作为消息发给拿着这张卡的 agent。点完后 5 秒内可以撤销。
- **进行中**：标题、下一步，以及拿卡 agent 的实时状态（在跑、停了、出错）；停了的排在最前面。
- **等别的**：在等什么、等了多久。
- **没人接**、**完成**：各收成一行，点开再看。

顶部一行说清两件事：有几件在等你，事情是不是在推进（「2 等你 · 3 在跑 · 1 停了」）。

## 一张卡片

标题、谁在做、在等什么、下一步、清单、说明和记录。清单写的是完成前必须满足的条件（比如「PR 已合并」「测试机已清理」），有没勾的项就不能标完成。每一次修改都会自动记一行，写明是谁、什么时候改的。

点开卡片可以：答复、勾清单、完成或重开、交给某个 agent（它会收到接手这张卡的消息）、改标题和说明、删除。右上角「+」新建卡片。手机上卡片从底部弹出，电脑上显示在列表旁边。

## agent 怎么用

agent 只用两个工具：一个读看板（`kanban__board`），一个改卡片（`kanban__set`）。开始、卡住、做完、交接时更新自己的卡；要你拍板就在卡上提问，不在聊天里问。说「看看看板」或「把这张卡拿去做」就行。

## 放在哪里

- **群看板**：在群或私聊的右栏「⋯」里打开，保存在对话的文件夹（`协作看板.board.json`），成员和各自的 agent 一起看、一起改，实时同步，手机上也能用。
- **本机看板**：在左侧栏打开，保存在这台电脑的应用数据目录（`board.json`），只在电脑上使用，卸载应用时一并删除。

群消息里可以发一张看板摘要卡片，显示等你、进行中、等别的数量和第一个等你答复的问题，点一下打开看板。

1.x 的看板会自动迁移：列、进度、链接、评论和决策都会转进卡片的说明或记录，不丢内容；群文件的历史版本里保留着旧内容。
