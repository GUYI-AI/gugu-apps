在微信读书里读书、划线，想问的时候在咕咕里问。

连上之后，侧栏里就是你正在读的书（读到第几章、进度、读了多久）和刚划的线。点一条划线，选「解释这段」「换个角度」或「展开联想」，划线原文、出处和你写的想法就一起放进对话框，你按发送就行。碰到数学、计算机这类难点，先在微信读书里把那段划出来，再到这里问。「按书看笔记」按章节列出一本书的全部划线和想法，一键让 agent 按主题整理成读书笔记，在群里还能直接存进群文件夹。

agent 也能自己读：问它「我刚划的那句什么意思」「我在读什么」「把这本书的笔记整理一下」，它会去取你最新的划线、想法和阅读进度。

用的是微信读书官方开放的接口（微信读书 Skill）：在微信读书 App 的「我 › 设置 › 微信读书 Skill」或 weread.qq.com/r/weread-skills 登录后取一个 API Key（wrk- 开头），贴进来一次就好。接口不提供书的正文，agent 读到的是你的划线、想法、章节和进度。只在电脑上运行。
