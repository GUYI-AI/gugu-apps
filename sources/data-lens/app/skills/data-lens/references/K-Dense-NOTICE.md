# K-Dense attribution

The exploratory and statistical analysis guides in this directory are adapted from
[Scientific Agent Skills](https://github.com/K-Dense-AI/scientific-agent-skills) by K-Dense Inc.,
commit `a25cf9ec00e2745d03f8704acf6f6919694ccd9a`:

- [exploratory-data-analysis/SKILL.md](https://github.com/K-Dense-AI/scientific-agent-skills/blob/a25cf9ec00e2745d03f8704acf6f6919694ccd9a/skills/exploratory-data-analysis/SKILL.md), version 1.4.
- [statistical-analysis/SKILL.md](https://github.com/K-Dense-AI/scientific-agent-skills/blob/a25cf9ec00e2745d03f8704acf6f6919694ccd9a/skills/statistical-analysis/SKILL.md), version 2.0.

The adaptation selects tabular-analysis reasoning and routes computed CSV results through the existing host
file-send and Data Lens card workflow. It does not distribute the upstream scripts, domain-format inspectors
or scientific Python dependencies.

Background: Kassis, T., Agarwal, V., He, Y., Patel, D., & Brueckner, A. M. (2026).
*Scientific Agent Skills: A Library of Procedural Knowledge for Research Agents*.
[arXiv:2609.00065](https://doi.org/10.48550/arXiv.2609.00065).
