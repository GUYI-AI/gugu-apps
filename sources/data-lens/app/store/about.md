Turn a chat's data files into charts and tables that everyone in the chat can read.

## Cards in the chat

Ask an agent about a spreadsheet, a CSV or a SQLite database in the chat — "revenue by region this quarter", "orders per month". It looks at the file, writes the query and sends a card: a bar or line chart, a scatter, a heatmap for a pivot, a table, or the key figures.

- Hover or tap a chart for the exact values; click a column header to sort a table.
- **Open** shows the whole file in Data Lens: every table, your own queries, the same views.
- **Ask an agent** drafts a question about the card for you to send.

## Your data stays where it is

A card holds no data — only which file (and which version of it), the query and how to draw it. Each person's device reads the file from the chat and computes the card itself, so a card shows the same numbers to everyone, even after the file changes. Data Lens only reads files; it never changes them and never sends data anywhere.

Reads `.csv`, `.tsv`, `.xlsx`, `.xls`, `.ods`, `.sqlite`, `.db`, up to 25 MB. On desktop and phone.
