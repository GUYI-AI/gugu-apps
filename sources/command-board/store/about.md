群里一块看板：交代出去的每件事是一张卡，按「球在谁手里」分五列——待开工、在做、轮到你、进下一版 Beta、已交付，另有「搁置」。

要你拍板的卡放在「轮到你」：agent 写好选项和建议，你点一下，或者「全按建议」，看板就以你的名义告诉负责的 agent，卡自己挪回「在做」。看稿的卡点「行」或「打回」并写一句原因。

点开一张卡：时间线只记里程碑，下面是待办、你拍过的板、评论；「去聊」直接跳到负责这件事的话题或会话。对话和代码改动留在咕咕本来的地方，看板只管派活、拍板、看进度。

agent 按卡的 ID 读写：`task` 一次读全一张卡，连同整板的规矩和记忆；`log` 记里程碑，`todo` 改待办，`comment` 写评论，`cards` / `put` 看整板、建卡和换列。你立的规矩，agent 读卡时先读到，照办不再问你。
