这个 App 管的是你在咕咕「资源库 → 提示词」里存的那一份，也就是你在输入框敲 `/` 时用的那些。它没有自己的提示词库，也没有自己的页面：装上以后，你的 agent 可以读取和维护资源库里的这一份。

- 「把这段存成提示词」：agent 新建一条，资源库里马上多出它，输入框敲 `/` 就能用；
- 「我的提示词里有哪些重复的？」：agent 读出你的全部提示词，帮你合并、改写；
- agent 删掉的提示词，你当场会看到提示，并能撤销。

你自己照旧在「资源库 → 提示词」里新建、编辑、删除。你和 agent 改的是同一份，它跟着账号走，换一台电脑也在。

其他 App 自带的提示词，agent 只能读，不能改。不装这个 App，agent 看不到你的提示词，也不多占上下文。
