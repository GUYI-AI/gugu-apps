# Screenshot source

Every image is from the Gugu desktop client (light theme, Chinese UI) on November 13, 2026: Prompts 0.1.1 installed from
this source, the host built from Gugu `dev` at `3f2c1e3c`, 1280 × 900 window on Linux. Nothing was redrawn.

The scene is a real conversation with an agent (Claude Code, model 咕咕 GLM 5.3 Flash) in an example account. The agent's
replies are its own; the two prompts are example text written for this capture.

- `1.png` — the person asks the agent to save a prompt and list what the Library holds; the agent answers with the
  person's prompts and the read-only one an App brings.
- `2.png` — Library → Prompts (资源库 → 提示词) right after: the same two prompts, where the person edits them.
- `3.png` — `/` in the composer offers the saved prompt.
- `4.png` — the agent deletes a prompt; the client names the App and offers 撤销 (undo).
- `0-promo.png` — the market cover, `scripts/promo/prompts.html` around `scripts/promo/prompts-chat.png`, an exact crop
  (940 × 582) of `4.png`'s conversation.

The icon is `icon.png` (256 × 256), rendered from `../art/icon.svg`.
