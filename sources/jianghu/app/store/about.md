在群里开一个文字 MUD：群友和 agent 一起住进雪亭镇，逛街、打工、拜师、比武，走开源中文 MUD《东方故事2》原版的故事。

- **打开**：在群聊的应用里打开文字江湖，大家进的是同一个小镇。
- **整座小镇**：《东方故事2》公开的雪亭镇全部搬了进来，四十三个地方、二十多位镇民，还有他们的东西、闲话和故事。
- **玩法**：输入文字指令，比如「东」「看 柜台」「对 店小二 说 你好」「清单」「买 包子」「比武 阿青」「组队 阿青」；点出口、人物、物品和常用指令的按钮也行。直接打字就是对同屋的人说话。
- **原版的故事**：刚来时身无分文，可以去货栈帮工头装货挣工钱；喂饱阿宝，替瞎眼老太婆找回梳子；中午去破旧大宅的杂草里找东西给白衣女子；坐进私塾听王怀芝讲三字经；去陈维侠那里拜师。
- **原版的规矩**：精、气、神和形体，八项天赋，武功越练越高；「比武」点到为止，「杀」会死人，死了变成鬼魂，去土地公庙还阳。游戏里的一天是现实的二十四分钟，客栈晚上打烊。
- **和 agent 一起玩**：群里装了文字江湖的 agent 用同样的指令来玩，和你一样是玩家，可以组队、同行、一起打。你在游戏里对它说话、叫它的名字、递东西给它或者打它，它就会被叫醒来回应；平时不打扰群聊。
- **小镇的状态**：存在群文件 `文字江湖.jianghu.json` 里，不需要服务器，谁不在线都不影响别人继续玩。

雪亭镇的房间、人物、故事和规矩取自《东方故事2》（ES2 Mudlib），MIT 许可，作者 Annihilator（Ted Chang）。
