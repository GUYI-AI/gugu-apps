在群里开一个文字 MUD：群友和 agent 一起从长安出发走取经路，拜师、练功、闯关，走老中文 MUD《西游记》原版的故事。

- **打开**：在群聊的应用里打开西游，大家进的是同一个世界。
- **玩法**：输入文字指令，比如「东」「看 店小二」「对 店小二 说 你好」「清单」「买 花生豆」「比武 阿青」「组队 阿青」；也可以点方向键、人物和物品旁的动作、常用指令。直接打字就是对同屋的人说话。
- **像素画面**：自己画的像素风，红心、闪电、鸡腿、水滴各十格，显示气血、精神、食物和水；方向键固定九格，走不通的方向是灰的，上楼、进门这类出口直接打字。新角色进来先看一屏开场，然后落在长安。
- **西游**：新角色出生在《西游记》的长安，拜张果老学艺，练内力法力，沿取经路往西闯关：五庄观偷人参果，宝象国救百花公主，平顶山斗金角银角，乌鸡国救国王，车迟国斗三大仙，通天河降金鳞怪。剧情照原版，组队闯关功劳一起算，老玩家带新人就能过宝象国。
- **规矩**：气血、精神、内力、法力和道行，武功越练越高；「比武」点到为止，「杀」会死人，死了变成鬼魂，去长安的城隍庙还阳。玩家之间只能对在线的人下杀手，agent 不会被玩家杀死。游戏里的一天是现实的二十四分钟。
- **和 agent 一起玩**：群里装了西游的 agent 用同样的指令来玩，和你一样是玩家，可以组队、同行、一起打。你在游戏里对它说话、叫它的名字、递东西给它或者打它，它就会被叫醒来回应；平时不打扰群聊。
- **世界的状态**：存在群文件 `西游.jianghu.json` 里，不需要服务器，谁不在线都不影响别人继续玩。

长安和取经路（五庄观到通天河）取自《西游记》4.5（神话世界·西游记），作者 snowcat、weiqi、mon 等。像素字体是字言字语的精品点阵体 9×9（OFL 许可）。
