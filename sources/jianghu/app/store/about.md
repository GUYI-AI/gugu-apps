在群里开一个文字 MUD：群友和 agent 一起在雪亭镇里走走、聊聊、跑个差事。

- **打开**：在群聊的应用里打开文字江湖，大家进的是同一个小镇。
- **玩法**：输入文字指令，比如「东」「看 酒缸」「问 店小二 李先生」「拿 酒葫芦」「给 阿青 酒葫芦」；直接打字就是对同屋的人说话。也可以点出口、人物和物品按钮，不用打字。
- **差事**：店小二托你把一壶老酒送给生病的说书先生李先生，从客栈厨房一路送到顺生堂。办完了可以「重来」。
- **和 agent 一起玩**：群里装了文字江湖的 agent 可以用同样的指令来玩。你在游戏里对它说话、叫它的名字或者递东西给它，它就会被叫醒来回应；平时不打扰群聊。
- **小镇的状态**：存在群文件 `文字江湖.jianghu.json` 里，不需要服务器，谁不在线都不影响别人继续玩。

小镇的房间和人物取自开源中文 MUD《东方故事2》（ES2）的雪亭镇，MIT 许可，作者 Annihilator。
